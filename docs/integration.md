# Интеграция frontend и backend

Срез: 21 октября 2026 года. Проверены [backend `3588c36`](https://github.com/MedPredicts/backend/tree/3588c363e3d34946d86ce75be39a5695a8073176) и исходники [организационного frontend `c5c24ef`](https://github.com/MedPredicts/frontend/tree/c5c24ef0d8475bb0b67a5611c0ed00b656e7318b). Документ описывает HTTP-интеграцию frontend и backend и оставшиеся задачи подключения модели.

## Что работает

- Настоящий Spring Boot отдаёт описание полей; фронтенд строит форму и отправляет плоский JSON в `POST /api/v1/predictions`.
- Ответ проверяется по типам и единицам. Сохраняются ввод, отмена, явный повтор, защита от устаревших ответов и фокус ошибочного поля.
- Ошибки `INVALID_REQUEST`, `VALIDATION_ERROR`, `MODEL_UNAVAILABLE` и общие 5xx различаются. Запросы получают язык выбранного интерфейса через `Accept-Language`.
- Серверный `demo-example` явно подписан в интерфейсе и PDF. Он не превращается в автономное демо: данные действительно отправляются серверу.
- Обычный запуск и production-сборка используют HTTP. Автономное демо запускается отдельной командой. Нет автоматического переключения при сбое сервера.

## Запуск связки

Нужны JDK 17+, Node.js 22.12+ и npm. Maven скачивается wrapper-скриптом backend. База данных для текущего сценария не требуется.

Терминал 1 — backend:

```sh
git clone https://github.com/MedPredicts/backend.git
cd backend
bash ./mvnw spring-boot:run -Dspring-boot.run.profiles=demo
```

В Windows: `.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=demo"`.

Терминал 2 — frontend:

```sh
git clone https://github.com/MedPredicts/frontend.git
cd frontend
npm ci
npm run dev
```

Открыть [127.0.0.1:5173](http://127.0.0.1:5173). Vite проксирует `/api` на `http://127.0.0.1:8080`. Для другого порта backend создайте `.env.local` по `.env.example` и измените `API_PROXY_TARGET`, затем перезапустите Vite. Не добавляйте `/api/v1` в target: путь уже включён в запросы.

Синтетический пример: возраст `52`, пол `male`, ИМТ `27,4`, холестерин `5,6`, глюкоза `5,9`. В серверном demo ответ всегда `134,2 мм рт. ст.` независимо от ввода.

Без `-Dspring-boot.run.profiles=demo` текущий backend возвращает `503 MODEL_UNAVAILABLE` на GET и POST. Фронтенд сообщает о недоступной модели и блокирует отправку. Это ожидаемое поведение, пока реальный провайдер не подключён.

### Автономная демонстрация

```sh
npm run dev:demo
# Или отдельная demo-сборка:
npm run build:demo
npm run preview
```

Она не отправляет показатели серверу. Локальные `.env.local` и переменные процесса имеют приоритет над `.env.demo`; при ручном переопределении режима проверьте показанную в шапке подпись. Сценарий задаётся `VITE_DEMO_SCENARIO=success|validation|unavailable`.

### Production

`npm run build` собирает HTTP-версию. Разместите `dist/` и настройте reverse proxy `/api` к Spring Boot, без изменения `/api/v1/...`. Альтернатива — задать `VITE_API_BASE_URL=https://<адрес-api>` перед сборкой и добавить точный origin сайта в backend `CORS_ALLOWED_ORIGINS`. `VITE_*` публичны и не должны содержать секреты. Vite proxy применяется при разработке и не заменяет настройку сервера размещения.

Backend по умолчанию разрешает CORS для `http://localhost:5173` и `http://127.0.0.1:5173`; credentials не используются. Для других origin, включая локальный preview на 4173, нужна явная настройка allowlist. HTTPS и запрет записи медицинского body в access/APM/debug-логи настраиваются на сервере размещения. Публичный адрес API в репозиториях не задан.

## Чего ещё не хватает

| Пункт | Где / ответственный | Что нужно для завершения |
|---|---|---|
| Обученная модель | Модель / Али | Артефакт, версия, checksum, датасет и независимая оценка |
| Реальный inference | Backend / Оралхан + Али | `PredictionModel` вместо `UnavailablePredictionModel`, загрузка артефакта и обработка недоступности |
| Согласованные признаки | Модель + backend | Точные единицы, категории, порядок и preprocessing как при обучении; только утверждённые ограничения |
| Численная проверка | Вся команда | Контрольные входы/выходы, сравнение Python и Java/inference с допустимой погрешностью |
| Общий онлайн-запуск | Backend + frontend | Адреса размещения, HTTPS, reverse proxy/CORS и проверка production-сборки на этом окружении |
| Полная локализация данных модели | Backend + frontend | Переводы metadata и успешного disclaimer: сейчас сервер отдаёт их на русском |
| Вход и история, если нужны продукту | Backend + frontend | Сейчас нет auth/history endpoints и экранов; согласовать требования и правила хранения перед реализацией |
| Выбор M1/M2/M3 и временные ряды, если нужны | Модель + backend + frontend | Сейчас API описывает один активный показатель; нужны отдельный контракт выбора и формат последовательностей |

Последние два пункта не блокируют текущий одностраничный сценарий прогноза. Подключение ML и размещение нельзя считать выполненными по успешному ответу demo. Медицинская точность фиксированного примера не измеряется.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run build:demo
npm run test:e2e
# Backend должен работать на 8080 с профилем demo, порт 5173 должен быть свободен:
npm run test:integration
```

`test:e2e` проверяет синтетические ответы на 4173/4174. `test:integration` поднимает HTTP-фронт на 5173 и обращается к настоящему Spring Boot через Vite proxy без подмены ответов: GET → форма → POST → маркированный результат → PDF; отдельно — серверная валидация, `Accept-Language`, фокус и успешный повтор. Viewports: 1440×1100 и 390×844. Скриншоты и PDF интеграционного теста сохраняются в системной временной папке `medpredict-integration-results`.

При проверке этого среза прошли typecheck, lint, 83 unit-теста, обе сборки, 42 обычных E2E и 4 сквозных теста с Spring Boot. Отдельно подтверждены GET/POST `503 MODEL_UNAVAILABLE` без профиля, `Cache-Control: no-store` и CORS preflight с `Content-Type` / `Accept-Language`. Проверка выполнена в Chromium; Firefox, Safari, реальный ML и сервер размещения не проверены.

| Браузерная проверка | Результат |
|---|---|
| Адрес, title, содержимое первого экрана | Пройдена |
| Ошибки приложения, console error/warning и Vite overlay | Не обнаружены в успешном сквозном сценарии |
| Настоящий POST и маркированный результат | Пройдена на desktop и mobile |
| Ошибка серверного поля, фокус, сохранение ввода, повтор | Пройдена на desktop и mobile |
| PDF без повторного POST | Скачивание прошло; извлечённый текст содержит demo-пометку, значение, версию и disclaimer сервера |
| Переполнение по горизонтали и скриншоты результата | Проверены на 1440×1100 и 390×844 |

Browser plugin в сессии отсутствовал; использован установленный в проекте Playwright. Предупреждения `NO_COLOR/FORCE_COLOR` относятся к окружению запуска Node, а не к console браузерного приложения.

Фронтенд не пишет показатели в localStorage/sessionStorage, URL, аналитику или логи. Текущий backend не сохраняет прогнозы и не логирует body. PDF содержит только данные, которые пользователь сам экспортировал.
