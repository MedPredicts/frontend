# MedPredict frontend

Медициналық көрсеткіштерді болжауға арналған оқу жобасының фронтенді. React + TypeScript + Vite, қазақша / русский / English интерфейсі, деректерді тексеру, API адаптері және PDF экспорты.

Бұл жарияланым — бір беттік demo нұсқасы. Figma арқылы жасалған кеңейтілген интерфейс кейін бөлек қосылады. Репозиторийде фронтенд коды, ресурстары, тесттері және API интеграциясына арналған құжаттар бар. Java / Spring Boot сервері мен модель бөлек әзірленеді.

## Іске қосу

Node.js 22.12+ және npm қажет.

```sh
git clone https://github.com/MedPredicts/frontend.git
cd frontend
npm ci
npm run dev
```

Жергілікті адрес: http://127.0.0.1:5173. `.env.development` файлында demo режимі қосылған. Demo нәтижесі — интерфейсті тексеруге арналған бекітілген мысал; енгізілген деректер бойынша есептелмейді және медициналық қорытынды болып саналмайды.

## Demo жинағы

`.env.production` файлында demo режимі қосылған, сондықтан қосымша баптаусыз жинақтауға болады:

```sh
npm run build
npm run preview
```

Жинақталған demo серверге болжам сұрауларын жібермейді. Нәтиже — енгізілген деректерге тәуелсіз, бекітілген мысал. Demo сценарийлері: `success`, `validation`, `unavailable`.

## Болашақ API интеграциясы

API адаптері кейінгі интеграция үшін сақталған; жарияланатын demo оны пайдаланбайды. `GET /api/v1/model/info` — фронтенд ұсынған алдын ала контракт, backend командасымен келісуді қажет етеді. Толық форматтар: [API контракты](docs/api-contract.md).

`.env.example` — жергілікті баптау үлгісі. `VITE_*` айнымалылары браузерге беріледі, оларға құпия деректерді жазбаңыз. Real режиміндегі қате demo режиміне автоматты ауыстырмайды.

## Тексерулер

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E тесттері синтетикалық мысалдар мен API жауаптарын алмастыруды пайдаланады. Серверлердің порттары — 4173 және 4174.

## Құрылым

- `src/` — бет, компоненттер, енгізуді тексеру, API, аудармалар және PDF.
- `public/` — логотиптер, жалаушалар және жергілікті қаріптер.
- `tests/` — Playwright сценарийлері.
- `docs/api-contract.md` — алдын ала API контракты.
- `docs/design/icons.md` — түстер, иконкалар және ресурстардың дереккөздері.

Көрсеткіштер тек ағымдағы React күйінде сақталады; `localStorage`, `sessionStorage`, аналитика немесе фронтенд логтарына жазылмайды. PDF пайдаланушы экспорттаған деректерді қамтиды.

Noto Sans қарпі [OFL лицензиясымен](public/fonts/OFL.txt) таратылады. Иконкалар — [Flaticon Uicons](docs/design/icons.md).
